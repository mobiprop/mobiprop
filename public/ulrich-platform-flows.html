Who Uses the Platform

Four distinct user types, each with a different entry point and set of permissions
🌐

Public Visitor

No Account
  • Browses listings freely
  • Uses search & filters
  • Views property detail pages
  • Reads blog & about pages
  • Fills contact / inquiry form
  • Submits tour request
  • Cannot save favorites yet
🏠

Registered User

Buyer / Seller
  • Everything a visitor can do
  • Saves / favorites listings
  • Schedules property tours
  • Views own contracts
  • Tracks scheduled tours
  • Manages profile & preferences
  • Receives tour email confirmations
👤

Agent (Staff)

Invite-Only
  • Registers via invitation link
  • Accesses internal dashboard
  • Manages own listings
  • Handles assigned leads
  • Manages own opportunities
  • Views own revenue / deals
  • Communicates with contacts
  • Cannot see all company revenue
⚙️

Admin / Manager

Full Access
  • All agent capabilities
  • Full revenue visibility
  • Invites & manages agents
  • Manages all listings globally
  • Views all leads / contracts
  • Configures platform settings
  • Manages office locations
  • Accesses integrations
  • Reads full activity logs

Step-by-step walkthrough

1

Lead enters the system

Someone fills the contact form, schedules a tour, or an agent manually adds them. They are scored (Cold/Warm/Hot) and assigned to an agent.

Source: website formScore slider 0–100Auto-notifies agent
2

Lead becomes a Contact

Once the agent has spoken with them, the lead is promoted to a Contact with full details: name, type (Buyer/Seller/Agent), location, linked property interest.

Buyer / Seller / Agent typeLinks to listingNotes & history
3

Opportunity opened

Agent creates an Opportunity linking the Contact + Listing. Moves through stages: Qualification → Visitation → Offer → Negotiation → Closing. Tracks commission amounts and creation date.

5 pipeline stagesCommission trackedExpected close dateCreation date
4

Contract created

If the opportunity closes as Won, a Contract is created. Includes type, value, contingencies, terms, and document uploads (PDF/DOC). Status: Pending → Active → Completed.

Document uploadExpiry trackingExpiry notifications
5

Revenue recorded

Once a contract is marked Completed, the revenue value flows into the Dashboard — showing total revenue, agent performance, location summaries, and the sales summary table.

Every module in the CRM eventually connects back to either a Listing (the property) or an Agent (the person responsible). Listings and Agents are the two anchor records everything else hangs from.

Cross-module relationship table

Module Connects to How they relate
Listing Agent · Location · Opportunity · Contract Each listing is assigned to an agent and a location. Opportunities and contracts reference the listing as the "property" field.
Lead Contact · Agent · Listing A lead has a "property interest" field that links to a specific listing. When qualified, the lead is promoted to a Contact. The lead is assigned to an agent.
Contact Lead · Opportunity · Contract · Listing · Message Contacts are the client records. A seller contact can link directly to a property listing they own. Contacts appear in opportunities as the "client" side.
Opportunity Contact · Listing · Agent · Contract An opportunity always has: one contact (the buyer/seller), one listing (the property), one agent. When marked Won, it spawns a Contract.
Contract Opportunity · Listing · Contact · Agent Contracts reference the listing, the counterparty contact, and the responsible agent. Revenue is derived from the contract value when Completed.
Agent Listing · Lead · Opportunity · Contract · Location · Message Agents are assigned to listings, own leads, manage opportunities, sign contracts, and belong to an office location. Dashboard shows their individual performance.
Location Listing · Agent Locations are office areas or regions. Listings belong to a location. Agents are assigned to a location. Dashboard shows per-location revenue and property count.
Message Contact · Agent Messages connect an agent (or admin) with a contact (or public user via front-end DM). The same inbox handles both internal agent chat and customer inquiries.

Every action on the platform — from a visitor clicking a listing to an admin closing a contract — flows through this connected system. The database is the single source of truth; Auth controls who can access what; the CRM is where the business happens; and the supporting systems (email, notifications, storage, logs) make sure nothing is missed.

Key rules that hold everything together

RuleWhy it matters
Every listing has one agent owner Ensures accountability. The listing shows on that agent's performance stats. Agents only see and edit their own listings.
Every opportunity has one contact + one listing Forces clean data entry. You can't have a deal without knowing who the client is and which property is involved.
Revenue only comes from completed contracts Dashboard revenue numbers are always accurate — they don't count pending or active contracts, only completed ones.
Agents can only see their own data by default Protects company-wide information. An agent sees their leads, deals, and commission — not the whole company's revenue.
Contracts track expiry dates The system automatically notifies admin and the responsible agent before a contract expires — this is critical for rentals.
Every change is logged Activity logs record who changed what, when, and what the previous value was. Deleted records are not lost — they're archived.
Agent registration is invite-only Prevents unauthorised access. Admin generates a time-limited token URL. Anyone without an invite cannot create an agent account.
Listings on website = listings in CRM There is one source of truth. When an agent publishes a listing in the CRM, it immediately appears on the public website. No manual sync needed.
