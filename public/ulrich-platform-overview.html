Section 1
The two parts of the platform
Ulrich Propiedades has a public website that clients use, and a private dashboard that staff use. They share the same data.
🌐

Public Website

What buyers and sellers see when they visit the site. No account needed to browse.

Browse listings Search & filter Book a tour Send an inquiry Read the blog About us
🔒

Internal Dashboard

The back-office tool only agents and admins can log into. Hidden from the public entirely.

Manage leads Manage listings Track deals Contracts Contacts Revenue reports
They share the same data. A listing published in the dashboard appears on the website instantly. A contact form submitted on the website creates a lead in the dashboard immediately — no manual copying needed.
Section 2
Who uses the platform
Four types of people interact with Ulrich Propiedades, each with a different level of access.

Visitor

No account required
  • Browses and searches listings freely
  • Views property detail pages
  • Sends a contact message
  • Requests a property tour
  • Reads the blog and About page
  • Cannot save favourites yet

Registered User

Buyer or seller with an account
  • Everything a visitor can do
  • Saves favourite listings
  • Tracks their scheduled tours
  • Views their own contracts
  • Manages their profile
  • Receives email confirmations

Agent

Staff — invited by admin only
  • Accesses the internal dashboard
  • Manages their own listings
  • Handles their assigned leads
  • Tracks their own deals & contracts
  • Communicates with contacts
  • Cannot see other agents' data or company revenue

Admin / Manager

Full control of everything
  • Everything an agent can do
  • Sees all agents and their performance
  • Views full company revenue
  • Invites and manages agents
  • Manages all listings and locations
  • Configures platform settings
  • Reads activity logs (who changed what)
Section 3
How a new inquiry becomes a closed deal
Every deal starts with someone showing interest. Here's how that becomes revenue — step by step.
1

Someone fills a form on the website

A contact message, tour request, or property inquiry — it all arrives automatically in the dashboard as a new Lead. The assigned agent gets notified right away.

2

Agent reviews and qualifies the lead

The agent calls or emails the person, scores them as Cold, Warm, or Hot, and adds notes. Once they're qualified and ready to proceed, the lead is promoted to a Contact.

3

Agent opens an active Deal

The agent links the Contact to a specific property listing and opens a Deal (called an Opportunity in the system). The deal then moves through stages:

Qualification → Property visit → Offer made → Negotiation → Closing

4

Contract created

If the deal is won, a Contract is created. The agent uploads the signed documents, sets the contract value, and tracks the expiry date. Status goes from Pending → Active → Completed.

5

Revenue recorded on the dashboard

Once a contract is marked Completed, the revenue value automatically appears on the admin dashboard — showing total revenue, per-agent performance, and per-location summaries.

What triggers a notification
The platform automatically notifies the right people when something important happens.
Trigger
🗓️ Tour booked by a visitor
  • Confirmation email sent to the visitor
  • Alert sent to the assigned agent
  • New lead created in the dashboard
Trigger
📩 New contact form submitted
  • New lead created in the dashboard
  • Notification sent to admin and agents
  • Alert sent to the assigned agent
Trigger
📄 Contract approaching expiry
  • Alert sent to the admin
  • Alert sent to the responsible agent
  • Warning badge shown on the dashboard
Trigger
👤 New agent joins the platform
  • Admin gets notified
  • Welcome email sent to the new agent
  • Activity log entry recorded
Trigger
🎯 Lead assigned to an agent
  • In-app notification sent to the agent
  • Lead appears on their dashboard
  • Optional email alert to the agent
Trigger
🏠 New listing published
  • Listing goes live on the public website
  • Optional team-wide notification
  • Activity log entry recorded
Section 6
Key rules that keep the platform clean
These are the built-in guardrails that ensure accurate data and proper accountability.
RuleWhy it matters
Every listing has one agent owner Ensures accountability. Agents can only see and edit their own listings. The listing counts toward their personal performance stats.
Every deal needs a contact and a property You can't open a deal without knowing who the client is and which property is involved. This keeps the data clean and trackable.
Revenue only counts from completed contracts Dashboard revenue numbers are always accurate — pending or active contracts are not counted until they're fully completed.
Agents only see their own data by default An agent sees their own leads, deals, and commission — not the whole company's revenue or another agent's pipeline.
Contracts track expiry dates The system alerts the admin and the responsible agent before a contract expires. This is especially important for rental agreements.
Every change is recorded in the activity log The admin can see who changed what, when, and what the previous value was. Deleted records are archived, not permanently removed.
Agents must be invited — no self sign-up Only an admin can generate an invite link for a new agent. Without an invitation, no one can create a staff account.
Website listings are the same as dashboard listings There is one single source of truth. When an agent publishes a listing in the dashboard, it appears on the website immediately — no manual sync needed.
